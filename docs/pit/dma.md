# DMA 乒乓缓冲

## 长度计算

可变长度接收不能直接把整个缓冲区交给协议层，而应根据 DMA 剩余传输数计算本次完成长度：

```c
dma_channel_disable(DMA0, DMA_CH2);
len = RX_SIZE - dma_transfer_number_get(DMA0, DMA_CH2);
```

读取长度后立即切换活动缓冲区，重新设置内存地址和传输数量，再清标志并恢复 DMA。已完成的缓冲区交给队列或协议任务处理。

## 常见错误

- 没有暂停 DMA 就读取剩余计数，导致长度不稳定。
- 切换缓冲区后仍让 DMA 写入旧缓冲区。
- 缓冲区交给上层后又被 DMA 覆盖。
- DMA 标志没有正确清除，造成重复中断。
- 片外 RAM 不在 DMA 可访问区域，或存在缓存一致性问题。

## 片外 RAM 检查

使用片外 RAM 作为 DMA 缓冲区时，至少确认：

1. DMA 控制器能访问该地址段。
2. 地址对齐、数据宽度和总线时序符合要求。
3. CPU cache 与 DMA 的读写方向已经同步。
4. 缓冲区不会与栈、堆或其他 DMA 区域重叠。

验证时同时记录缓冲区编号、实际长度、DMA 计数器和队列水位，才能区分硬件丢数与软件覆盖。
