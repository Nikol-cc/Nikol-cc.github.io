# 系统误操作恢复

## 恢复原则

系统文件被误删或启动服务异常后，优先恢复可观测性和连接能力，再恢复业务功能：

1. 使用串口确认系统是否仍能启动。
2. 检查根分区、挂载点和关键目录。
3. 恢复 SSH、网络和基本 shell 工具。
4. 恢复动态库、OpenSSL/OpenSSH 和 systemd 服务。
5. 最后恢复防火墙、应用和开机自启。

## 分阶段验证

```sh
mount
df -h
ls -l /bin/sh /usr/bin/ssh /usr/sbin/sshd
ldd /usr/sbin/sshd
sshd -t
systemctl --failed
```

每完成一阶段就保存日志和版本信息，不要在系统状态未知时一次性执行大量恢复命令。

## 预防措施

- 对系统目录操作前先打印当前路径和目标路径。
- 重要修改前制作可启动备份或保留可回滚镜像。
- 使用绝对路径和明确排除项，避免无范围的 `rm -rf`。
- 修改 SSH、防火墙和启动服务时保留串口入口。
- 把恢复步骤写成脚本或清单，避免只依赖记忆。
