# GD32F103 芯片资源

GD32F103 属于 GD32F10x 增强型系列，基于 Cortex-M3，主频最高 108 MHz。不同封装和料号的 Flash、SRAM、GPIO 数量及外设实例不同，下面先列系列级资源，实际选型必须以具体料号的数据手册和产品选型页为准。

## 资源概览

| 资源   | 系列级能力                                                |
| ------ | --------------------------------------------------------- |
| CPU    | Arm Cortex-M3，最高 108 MHz                               |
| 存储器 | Flash 约 16 KB ～ 3 MB，SRAM 约 6 KB ～ 96 KB，随料号变化 |
| 电源   | 常见工作电压 2.6 ～ 3.6 V                                 |
| GPIO   | 5 V tolerant 能力取决于引脚和具体料号                     |
| 定时器 | 高级控制、通用和基本定时器，支持 PWM、输入捕获、输出比较  |
| 通信   | USART/UART、SPI、I2C、CAN 2.0B、USB FS、部分料号支持 SDIO |
| 模拟   | 12 位 ADC，通道数和 ADC 单元数取决于封装                  |
| DMA    | 多通道 DMA，可用于 USART、SPI、ADC、定时器等请求          |

## 时钟与启动

常见时钟树由 IRC8M、外部 HXTAL、PLL、AHB、APB1 和 APB2 构成。配置外设前先明确：系统时钟、总线分频、定时器时钟倍频规则和 ADC 时钟上限。时钟切换后要更新 `SystemCoreClock`，否则延时、SysTick 和波特率计算会错误。

```c
rcu_periph_clock_enable(RCU_GPIOA);
rcu_periph_clock_enable(RCU_USART0);
gpio_af_set(GPIOA, GPIO_AF_1, GPIO_PIN_9 | GPIO_PIN_10);
gpio_mode_set(GPIOA, GPIO_MODE_AF, GPIO_PUPD_PULLUP,
              GPIO_PIN_9 | GPIO_PIN_10);
```

## 定时器与 PWM

PWM 频率由定时器输入时钟、预分频器和自动重载值决定：

```text
f_pwm = f_timer / ((prescaler + 1) × (period + 1))
duty  = pulse / (period + 1)
```

电机、舵机和 ADC 触发应优先使用硬件定时器输出或触发，避免用软件延时维持精确周期。

## USART、ADC 与 DMA

DMA 接收适合连续串口、ADC 扫描和 SPI 数据流。配置时同时确认 DMA 通道、请求源、数据宽度、内存递增、外设地址和传输方向。可变长串口接收要结合空闲线、定时器或协议长度确定本次有效字节数。

## 选型与验证清单

1. 根据封装确认 GPIO、ADC 通道、定时器通道和复用关系。
2. 检查 Flash/SRAM 是否满足 bootloader、应用和 RTOS 栈空间。
3. 核对 USART、CAN、USB、SDIO 是否与引脚复用冲突。
4. 以具体料号的启动文件、链接脚本和 CMSIS Pack 为准。
5. 用 `size`、MAP 文件和运行时栈水位确认资源余量，而不是只看标称容量。
