# GD32F407 芯片资源

GD32F407 是 GD32F4xx 中常用的 Cortex-M4F MCU，带 FPU、DSP 指令和丰富的高速外设。官方产品表中，GD32F407VGT6 为 LQFP100、最高 168 MHz、1 MB Flash 和 192 KB SRAM；同系列不同料号还可能提供 3 MB Flash、更大封装和更多 GPIO。

## 核心资源

| 资源     | 典型能力                                                       |
| -------- | -------------------------------------------------------------- |
| CPU      | Arm Cortex-M4F，最高 168 MHz，FPU/DSP                          |
| 存储器   | 典型 1 MB 或 3 MB Flash，192 KB SRAM，按料号变化               |
| 定时器   | 高级控制、通用定时器和基本定时器，支持互补 PWM、死区和刹车输入 |
| 通信     | USART/UART、SPI、I2C、CAN、USB OTG FS/HS、Ethernet MAC         |
| 存储接口 | FMC，可连接 SRAM、NOR/NAND、SDRAM 等外部存储器                 |
| 模拟资源 | 多单元 ADC、DAC，支持定时器触发和 DMA                          |
| DMA      | 多控制器、多通道和 FIFO，适合高速采样与通信                    |

## 高速时钟与 FPU

高主频带来更高吞吐量，但必须同时配置 Flash wait state、电源模式、PLL、AHB/APB 分频和外设时钟。浮点代码还要统一编译参数，避免硬件 FPU、软浮点 ABI 和库不匹配。

```sh
arm-none-eabi-gcc -mcpu=cortex-m4 -mthumb -mfpu=fpv4-sp-d16 \
  -mfloat-abi=hard -O2 -ffunction-sections -fdata-sections
```

## FMC 与外部 RAM

FMC 时序由地址建立时间、数据建立时间、保持时间、总线宽度、等待周期和访问模式共同决定。外部 RAM 可用于图像帧、DMA 乒乓缓冲或大数组，但要确认：

- DMA 控制器是否能访问该地址区域；
- CPU 和 DMA 的缓存/一致性策略；
- FMC 管脚复用、时钟和硬件布线；
- 读写时序是否通过逻辑分析仪或测试程序验证。

## Ethernet、USB 与 CAN

网络接口调试应分 PHY、RMII/MII 时钟、MAC、DMA 描述符、缓存和协议栈五层。USB OTG 要区分 FS/HS、主机/设备角色、VBUS、PHY 和端点配置。CAN 调试要核对位时序、终端电阻、过滤器和错误状态。

## 资源规划

链接脚本应把启动代码、只读常量、普通 SRAM、DMA 专用区和外部 RAM 明确分区。不要把“能链接”当成“能稳定运行”：启动后检查堆栈高水位、DMA 越界、总线错误和长时间压力下的内存覆盖。
